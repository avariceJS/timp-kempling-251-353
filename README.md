  Исполняемый файл: qt_tcp_server
  Порт: 5555, сервер запускается автоматически
  Образ публикуется на Docker Hub с публичным доступом
  Ссылка на образ прилагается текстовым файлом в Git

Вопрос 2 (программа):
  Многопользовательский сервер на C++/Qt на основе EchoServer.
  Тема: совместный редактируемый список (4 клиента).
  При подключении клиент получает приветствие.
  Если сервер занят (уже 4 клиента), он сообщает об этом,
  просит подключиться позже и сразу разрывает соединение.
  При каждом новом подключении всем рассылается текущее
  число подключённых клиентов.
  Команды:
    /add <элемент>    — добавить элемент в общий список
    /remove <элемент> — удалить элемент из общего списка
    /finish           — клиент закончил редактирование
  Когда все текущие подключённые клиенты отправили /finish,
  итоговый список рассылается всем клиентам.

=== СБОРКА И ЗАПУСК ===

Сервер (локально):
  cd server && qmake qt_tcp_server.pro && make
  ./qt_tcp_server

Клиент (GUI):
  cd client && qmake qt_tcp_client.pro && make
  ./qt_tcp_client

Docker:
  docker build -t akcelerator/qt_tcp_server:latest .
  docker run --rm -it -p 5555:5555 akcelerator/qt_tcp_server:latest
