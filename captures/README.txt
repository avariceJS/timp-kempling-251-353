# Скриншоты для ветки screens

Положите полноэкранные снимки в подпапки:

- `docker-build/` — консоль `docker build`
- `docker-run/`   — консоль `docker run` и старт сервера
- `program/`      — окна клиентов и вывод сервера (вопрос 2)
- `git/`          — консольные команды работы с репозиторием

Скриншоты должны захватывать весь экран компьютера.
